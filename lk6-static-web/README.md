# LH 雷火 

## 项目简介
- lk6-static-web
- LH雷火 Web page
- Node JS 版本: 推荐使用 16.17.0 
- 使用：Vue 3.0 、 Element Plus UI.
- Site Code: LK6.
- Site ID: 30


## 安装与部署

### NPM 安装
```
npm install
```

### 在 Local 浏览器打开 hot-reloads for development
```
npm run serve
```

### 打包并发布
```
npm run build
```
然后使用 /dist/ 文件夹里的代码发布。


## 分支管理
- 主分支 (production)： 主要版本，新开发时都从这个分支拉取最新数据
- 开发Staging分支 (staging)：开发中的代码，连接Staging数据库
- 开发UAT分支 (test)： 开发中的代码，连接Production数据库
- 功能分支 (feature/xxx)： 每个新功能一个分支
- Bug 修复分支 (hotfix/xxx)： 用于紧急修复问题
